# Vertical system identification and conservative PD pole placement

## Data and alignment

The fit uses the P-only and Kv=0.04 hardware runs. Only adjacent airborne
TAKEOFF/HOVER samples with both endpoints at least 0.02 m above the captured
ground and `0.01 <= dt <= 0.04 s` are retained. Landing, settle, confirmation,
ground-contact samples, and discontinuous timing are excluded. This leaves 398
velocity increments.

For interval `k -> k+1`, the command logged on row `k` is the command sent after
that state observation and held for the following interval. An additional delay
of 0–8 nominal 20 ms samples was scanned. The fitted integral equation is

```text
vz[k+1] - vz[k]
  = a * dt * (u[k-delay] - 0.425)
    - b * dt * (vz[k] + vz[k+1]) / 2
    + c * dt
```

This uses measured velocity increments and trapezoidal velocity integration;
it does not numerically differentiate velocity. Positive `a` means increasing
normalized thrust produces upward acceleration. Positive `b` opposes velocity.

Reproduce the analysis with:

```bash
python -m calibration identify-vertical-dynamics \
  calibration/runs/20261026T064847_690179Z_pitch-response-id \
  calibration/runs/20261026T065908_616181Z_cascaded-5c \
  calibration/stage5_analysis/vertical_system_id
```

## Identified local model

The shallow minimum in increment RMSE occurs at five samples, approximately
0.10 s additional delay:

| parameter | combined estimate | block-bootstrap 95% interval | units |
|---|---:|---:|---|
| `a` | 25.350 | 6.596–30.054 | m/s² per normalized thrust |
| `b` | 0.250 | -0.040–1.080 | 1/s |
| `c` | 0.207 | -0.065–0.304 | m/s² |

The velocity-increment RMSE is 0.00852 m/s per approximately 20 ms interval
(about 0.426 m/s² when divided by 0.02 s). The design-matrix condition number is
119.7. A contiguous 70/30 split gives held-out increment RMSE 0.00782 m/s and
R² only 0.072. Training on one flight and testing the other gives `a` of
28.37/31.33, but `b` of -0.205/0.671. The bootstrap produces positive `a` in
99.7% of samples, while `b` is much less certain.

The literal fit implies equilibrium thrust `0.425 - c/a = 0.4168`, but `a` and
`c` are strongly correlated and thrust is generated by closed-loop feedback.
The data therefore supports the sign and rough scale of thrust effectiveness,
not a new equilibrium-thrust calibration. Equilibrium thrust remains 0.425.

## Pole placement

For damping ratio 0.7, the nominal combined estimate gives:

| omega_n (rad/s) | Kp | Kv |
|---:|---:|---:|
| 0.9 | 0.03195 | 0.03983 |
| 1.1 | 0.04773 | 0.05088 |
| 1.3 | 0.06667 | 0.06193 |
| 1.5 | 0.08876 | 0.07297 |
| 1.592 (existing Kp=0.10 bandwidth) | 0.10000 | 0.07806 |

The existing Kp=0.10, Kv=0.04 corresponds nominally to damping ratio 0.397.
Selecting the exact 0.07806 result would nearly double Kv despite uncertain
damping and delay, so it is not recommended for the next flight.

The conservative candidate is **Kp=0.06, Kv=0.06**, zero velocity reference,
with Ki disabled. Nominally this gives omega_n=1.233 rad/s and zeta=0.718. Across
the correlated block-bootstrap samples with positive `a`, the 95% ranges are
0.632–1.343 rad/s and zeta 0.513–1.060; all sampled candidate characteristic
equations remain stable. These ranges describe identification sensitivity, not
formal guarantees.

## Historical-state command screening

| source states | reference mode | thrust range | saturation samples |
|---|---|---:|---:|
| P-only run | zero velocity | 0.39860–0.43605 | 0 |
| P-only run | ramp tracking | 0.40212–0.43605 | 0 |
| PD run | zero velocity | 0.39697–0.43127 | 0 |
| PD run | ramp tracking | 0.40297–0.43186 | 0 |

Under zero-reference damping, P-only landing states produce 0.41764–0.43378.
No replay reaches the unchanged 0.380–0.450 thrust bounds or the existing
-0.045/+0.025 correction limits. The candidate retains at least 0.01395 upward
and 0.01697 downward headroom on these states. Zero-reference damping opposes
the planned descent and may lengthen landing; position feedback still supplies
downward correction, but touchdown behavior is not established.

Historical-state replay is not closed-loop simulation. It cannot demonstrate
reduced overshoot, settling, or successful landing. No nonlinear simulation is
reported because the weakly identified bias/damping and unmodeled ground effect
would give false precision.

## Recommendation

The coefficients are **not reliable enough for precise physical identification
or aggressive exact pole placement**. They are sufficient to reject negative
thrust gain and to screen one lower-bandwidth, higher-damping diagnostic
candidate. The new, separate configuration is
`stage5c_altitude_pd_pole_candidate_config.json`; it changes only altitude Kp
and Kv relative to the zero-reference Stage 5C candidate. Attitude, heading,
XY, equilibrium thrust, thrust bounds, and safety thresholds are unchanged.

**GO for one explicitly authorized, supervised diagnostic flight with
Kp=0.06/Kv=0.06; NO-GO for treating these as validated final gains.** Review
takeoff velocity, peak altitude, HOVER RMSE, saturation, descent duration, and
touchdown confirmation before any further change. No automatic repetition or
gain update is justified.
